# Stage 1: Surgical Dataset Curation Pipeline

[![Hugging Face SFT Dataset](https://img.shields.io/badge/%F0%9F%A4%97%20Hugging%20Face-SFT%20Dataset-purple)](https://huggingface.co/datasets/shahedm2001/dataset_sft)
[![Hugging Face GRPO Dataset](https://img.shields.io/badge/%F0%9F%A4%97%20Hugging%20Face-GRPO%20Dataset-blue)](https://huggingface.co/datasets/shahedm2001/dataset_grpo)

An automated, end-to-end multimodal curation pipeline for constructing large-scale surgical Vision-Language Model (VLM) datasets for cataract surgery from multi-source operative video recordings.

This pipeline performs video acquisition, automated speech transcription (Whisper), LLM clinical refinement, procedural summarization, surgical VQA question generation, adverse event detection, temporal downsampling, train/val/test splitting, and formatting into structured Supervised Fine-Tuning (SFT) and Group Relative Policy Optimization (GRPO) formats.

---

## 🔗 Published Hugging Face Datasets

The final curated datasets generated by this pipeline are published on Hugging Face:

- **SFT Training Dataset**: [`shahedm2001/dataset_sft`](https://huggingface.co/datasets/shahedm2001/dataset_sft)  
  *5,597 video clips and 108 unclipped full procedures covering visual QA, instrument identification, step identification, and full narrative flow.*
- **GRPO Training Dataset**: [`shahedm2001/dataset_grpo`](https://huggingface.co/datasets/shahedm2001/dataset_grpo)  
  *4,758 prompt-response slices across 7 surgical tasks spanning MCQs, continuous temporal tasks (tIoU and boundary detection), and 13-class phase recognition.*

## 🏗️ Pipeline Architecture

The pipeline processes raw video recordings through an orchestrated sequence of 15 modular stages:

```
[YouTube / Clinical Videos]
         │
         ▼ (download)
[Raw MP4 Videos] ──► (clean) ──► (transcribe) ──► (refine) ──► (summarize)
                                                                    │
         ┌──────────────────────────────────────────────────────────┘
         ▼
[VLM Question Generation] ──► [Adverse Event Detection] ──► (downsample)
         │
         ▼ (split & format)
[Structured SFT & GRPO Samples] ──► (merge & format) ──► [Hugging Face Hub]
```

### Stage Details

1. **`download`**: Downloads high-resolution surgical videos from curated URLs (`youtube_links.txt`) via `yt-dlp`.
2. **`clean`**: Verifies container integrity, audio stream availability, and valid resolutions.
3. **`transcribe`**: Extracts audio tracks and transcribes surgical audio using OpenAI Whisper.
4. **`refine`**: Employs medical LLMs to correct ophthalmic terminology, anatomical names, and surgical jargon.
5. **`summarize`**: Generates structured, chronological procedural summaries of the entire surgical flow.
6. **`vlm`**: Synthesizes multimodal question-answer pairs anchored to specific video timestamps.
7. **`adverse_event`**: Detects intraoperative complications (capsule rupture, iris prolapse, hyphema).
8. **`downsample`**: Standardizes temporal frame rates and video dimensions (480p @ 5 FPS).
9. **`split`**: Generates balanced patient-level and procedure-level Train, Validation, and Test splits.
10. **`format`**: Assembles multimodal JSONL records conforming to conversation schemas.
11. **`merge`**: Consolidates clip-level and full-procedure datasets.
12. **`move_full_video`**: Preserves unclipped 108 full surgical videos for long-horizon narrative training.
13. **`narration`**: Compiles comprehensive full-procedure narration sequences.
14. **`refine_instrument_options`**: Validates MCQ distractors against standard ophthalmic surgical trays.
15. **`generate_missing_grpo_sft`**: Ensures complete pairing between deterministic GRPO rewards and SFT traces.

## 🚀 Quick Start

### 1. Installation

Requires Python ≥ 3.10 and [uv](https://docs.astral.sh/uv/):

```bash
cd 01_dataset_curation

# Option A: One-step environment setup
bash setup.sh

# Option B: Fast sync with uv
uv sync
```

### 2. Configure Environment

Copy the example environment template and insert your API credentials:

```bash
cp .env.example .env
```

Key environment variables:
- `REFINER_API_KEY`: API key for LLM transcript refinement.
- `GEMINI_API_KEY`: Google GenAI API key for multimodal video analysis.
- `VLM_GATEKEEPER_API_KEY`: Key for candidate sample verification.
- `PHASE_SFT_TEACHER_API_KEY`: Key for teacher-model phase supervision.

### 3. Run the Pipeline

Run the complete pipeline end-to-end:

```bash
uv run python cli.py
```

Run a specific pipeline step:

```bash
uv run python cli.py --step download
uv run python cli.py --step transcribe
uv run python cli.py --step format
```

Override default configuration:

```bash
uv run python cli.py --config config.yaml --step vlm
```

## 🔬 Phase SFT & GRPO Generation Tools

Phase-recognition clips feature a dedicated teacher/critic verification gate to guarantee clinical ground truth:

```bash
# 1. Generate teacher-critic verified SFT phase samples
uv run python -m tools.phase_sft_dataset --config config.yaml

# 2. Generate deterministic GRPO phase records (zero additional model calls)
uv run python -m tools.phase_grpo_dataset --config config.yaml

# 3. Merge verified phase samples into the final training dataset
uv run python -m tools.merge_phase_dataset --config config.yaml
```

## 📂 Subdirectory Structure

- `stages/`: Core implementations of each pipeline stage (`downloader.py`, `transcriber.py`, `vlm_generator.py`, etc.).
- `tools/`: Utility scripts for dataset packaging, phase generation, media processing, and verification.
- `common/`: Shared I/O utilities, Gemini clients, and LLM wrappers.
- `docs/`: Exhaustive technical specifications for every individual stage and tool.
- `academic_report.md`: Quantitative dataset composition report and clinical phase distribution.
- `GRPO_dataset_report.md`: In-depth analysis of task distributions and reward formulations for RL.
